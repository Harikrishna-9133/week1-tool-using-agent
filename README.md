[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)

An intelligent, single-purpose AI Agent built with Python and the **Groq API** (using OpenAI-compatible local function/tool calling). The agent receives natural-language math requests, decides when to trigger the `calculate` tool using `tool_choice="auto"`, prints the raw structured tool call, executes the calculation securely without `eval()` or `exec()`, and returns the final response to the user.

---

## 📌 Project Overview

This project was developed for **SkillAudit.ai Week 1 Assignment: First Tool-Using Agent**. 

### Key Features
- **Deterministic Tool Calling**: Utilizes `Groq` tool/function calling with `tool_choice="auto"`.
- **Strict Security**: Implements arithmetic logic via standard Python operators. No dynamic code execution (`eval` / `exec`) is used.
- **Raw Tool Call Visibility**: Prints the complete raw tool call generated by the LLM (Tool Call ID, Tool Name, Arguments) before execution.
- **Robust Error Handling**: Safely catches division by zero, invalid operations, invalid argument types, API errors, and missing environment variables.
- **Cross-Platform Compatibility**: Reconfigures UTF-8 encoding for Windows CMD / PowerShell environments.
- **Interactive CLI**: Interactive prompt loop supporting `exit` and `quit` commands.

## 🛡️ Safety & Error Handling

1. **No Unsafe Execution**: The `calculate` function directly uses Python standard operators (`+`, `-`, `*`, `/`). Dynamic code evaluation (`eval` / `exec`) is completely forbidden.
2. **Whitelisting**: Only functions present in `ALLOWED_TOOLS` (specifically `calculate`) can be invoked. Any unknown tool requested by an LLM is rejected immediately.
3. **Division by Zero**: Explicitly intercepted before calculation, returning an error dictionary payload: `{"error": "Division by zero is not allowed."}`.
4. **Environment Check**: Verifies `GROQ_API_KEY` before starting up and displays clear instructions if missing.

## 🎓 Key Learnings (SkillAudit.ai Week 1 Demo Takeaways)

1. **Tool Calling Protocol**: LLMs do not execute code themselves; they generate a structured JSON intent requesting tool execution.
2. **Message State Management**: To complete a tool call round-trip, the assistant message containing `tool_calls` must be appended first, followed by the tool response message with matching `tool_call_id`.
3. **Deterministic Temperature**: Using `temperature=0.0` ensures reliable, consistent tool selection and parameter extraction across user prompts.
